## 逐图通过标准

- 商品：瓶型、泵头、包装、标签及数量无明显变化。
- 中文：必须出现的已确认文案逐字一致；商品名、品牌、规格无错误，不增加功效。
- 构图：必需元素完整，无裁切、遮挡、额外商品或明显不可读文字。
- 光影：无明显悬浮和冲突阴影。
- 任一关键项失败不能交付；未看清为待核验，不能算通过。多模态只辅助，不能代替人工。
