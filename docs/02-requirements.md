# 初版需求与验收

状态：2026-09-15 开始本地出图流程实施；本轮范围见下。用户：无店铺、单人、本地使用。此前联盟流程保留为后续方向。

2026-09-16：企业产品业务是长期目标，单人本地仅为当前实现环境。最新用户反馈要求以产品项目统筹市场研究、产品策划、包装开发、生产交接、内容制作、运营反馈，素材生产只是先行模块。业务界面不展示开发者部署说明；既有后端能力、权限与未完成范围不因界面调整发生变化。具体下一阶段关系及完成条件见 05-ui-and-plan。

## 当前优先验收：整套商品图

1. 独立商品建档、编辑与版本留存，上传多角度产品图。默认空数据库；真实资料经显式导入。
2. 一套 5 张主图 + 默认 12 张详情图（详情数量 11–20）。主图用途：产品首图、核心卖点、香氛体验、发质诉求、规格信息。详情按定位、各卖点、香型、发质、规格及使用资料编排，缺失内容不自行编造。
3. 逐页编辑文字、关联卖点、素材、版式、配色与缩放。修改会撤销该页审核；关联商品资料更新后整套需重新核对。
4. 支持明确标记的草稿预览。正式批量导出要求全部页面审核且引用资料齐备；输出有序 PNG 和设计 JSON，保留历史版本与导出记录。JSON 可在本系统继续编辑，不承诺 PS 分层格式。
5. 未接模型时 AI 按钮说明未接入；不返回硬编码广告词或生成图片。真实 AI 输出必须保留候选状态和依据，不自动获得审核。
6. 类型检查、业务/API 测试、生产构建、浏览器验证、重启与备份恢复验证后分别报告结果。测试数据只能在临时测试目录使用。

## 首版范围
1. 创建与编辑选品项目：名称、目的、商品筛选条件。
2. 配置连接元数据、凭证环境变量引用和能力检测。真实凭证由用户在本地环境设置，不回传浏览器。
3. 使用已获批淘宝接口查询商品、加入项目并保存数据快照。
4. 基于选定快照提交分析任务，生成带证据的比较与建议。
5. 从商品素材或用户合法持有的参考图片生成新素材；原图、提示词、模型、参数、版本关联保存。
6. 查看与采用素材版本、下载结果；确认外观与事实由用户负责。
7. 任务列表、详情、进度、错误原因和有明确语义的重试操作。
8. 淘宝联盟推广链接、订单反馈：获得权限后实现和联调。未获批时显式展示未开通，不写模拟实现。

不做：真实付费广告投流、自有店铺 ERP、全网竞品数据库、自动发布、自动切换模型、多租户和工作流编辑器。京东留到淘宝流程验收后实际接入。

## 业务边界
- 联盟引单量不称为全店销量。缺失费用不计作零；未同步不计作无订单。
- 价格使用整数分或明确精度的十进制字符串，带币种；百分比与千分比在适配器转换并保留原口径。
- 重新同步生成新快照，不改写历史报告的输入。
- 加入项目、分析、生图为用户明确动作。数据来源中的文字不能作为系统指令执行。
- 商品素材可见不代表允许修改/再发布；生成前记录来源与用户的使用权确认，平台有额外限制时遵循官方约定。
- 商品报告允许比较实际可得指标，不使用编造的利润、销量、爆款概率或无依据评分。
- 生图结果不自动成为采用版本。修改提示词生成新的任务和素材。

## 验收矩阵
| 场景 | 预期行为 |
| --- | --- |
| 没有淘宝凭证 | 说明未配置，不能点击出一批假商品 |
| 已配置但未测试 | 状态仍是待验证；不声称权限正常 |
| 商品接口成功 | 标题、标识、来源、采集时间与原返回一致，字段口径可查看 |
| 相同商品多次同步 | 商品不重复，快照保留历史 |
| 一次分析多个商品 | 报告引用明确 snapshot 与字段，不串项目 |
| 模型返回非法 JSON/错误引用 | 标为输出无效，不保存为正式成功报告 |
| 生图成功 | 原图与输出可查看、版本可采用，文件落盘后任务成功 |
| 服务重启 | 已排队任务保留，执行中任务按租约与外部状态处理 |
| 重复点击同一提交 | 同一幂等键返回同一任务；同键不同输入返回冲突 |
| 外部生成超时 | 进入待核实状态，不无条件重复付费提交 |
| 已获批推广查询无订单 | 显示零订单及查询时间 |
| 无订单权限/查询失败 | 显示不可用或查询失败，不显示零订单 |
| 预算或并发不足 | 入队/领取受约束，多个同时请求不能越过额度预留 |
| 备份恢复 | 在独立临时目录验证数据库与素材引用一致，不覆盖工作数据 |

# 2026-09-16 首版实施边界

用户确认开始实施：市场研究基础流程、商品资料、商品内容交付。包装结构、研发生产、自动销售另行立项，不增加空业务入口。

- 市场研究：导入约定格式榜单，保存原始记录与来源；查看筛选、结合历史证据核对同款和老品，导出研究结果。无历史证据只标记新品候选，不能直接断定新品。三张表及迁移已获用户批准并实施。
- 商品资料：多商品、来源、素材与版本；不按某款洗发水硬编码其他商品的页面内容。
- 内容制作：先规划每页用途，再填写和确认文案、选择素材与版式、逐页审核、保存与交付。5 张主图、默认 12 张详情图。页面用途可修改，修改后必须重新审核；已有方案不自动重写。
- 完成标准：另一款商品也能独立建档、修改一页、保存版本并导出整套；外部文字和图片生成只有真实联调通过才算完成。
